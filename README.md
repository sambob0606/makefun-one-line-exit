A Python program that writes one original funny single-line resignation letter for [The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1) on make.fun.

The line:

> Dear Manager: I resign, effective immediately — I have accepted a position as my dog's assistant, and the benefits include naps.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
